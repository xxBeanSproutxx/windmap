### Task 2: Clip Grid Cells to Lake Polygon Boundary

**Objective:** Grid cells outside the lake polygon should not render. Use a point-in-polygon test to filter cells before drawing.

**Step 1: Add `pointInPolygon()` utility function**

Insert after the `impactWeight()` function (~line 634):

```js
// Ray-casting point-in-polygon test
function pointInPolygon(lat, lon, polygon) {
  let inside = false;
  for (let i = 0, j = polygon.length - 1; i < polygon.length; j = i++) {
    // polygon coords are [lon, lat] from KML
    const xi = polygon[i][0], yi = polygon[i][1];
    const xj = polygon[j][0], yj = polygon[j][1];
    const intersect = ((yi > lat) !== (yj > lat))
      && (lon < (xj - xi) * (lat - yi) / (yj - yi) + xi);
    if (intersect) inside = !inside;
  }
  return inside;
}
```

## Risks

- **Grid clipping performance:** Point-in-polygon runs for every cell (~500-1000 cells). The ray-casting algorithm is O(n*m) where n=cells and m=polygon vertices (~200). Should be fine for this scale (sub-100ms), but worth checking.
- **Wind card click vs Leaflet interaction:** The card sits above the map — ensure `click` events don't propagate to the map underneath. Add `e.stopPropagation()` if needed.
